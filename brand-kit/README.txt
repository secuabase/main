SECUABASE BRAND KIT  ·  v3 design system  ·  October 2026

01-Logo
  SVG/ and PNG/ (transparent background), in 5 layouts x 6 colorways:
  Layouts:   horizontal (main logo), horizontal-tagline, stacked, mark (icon only), wordmark
  Colorways: color          -> on white / light backgrounds (main)
             reversed       -> on Midnight blue or dark photos
             on-blue        -> on Persian blue only
             mono-midnight  -> one-color print
             mono-white     -> any dark or busy background
             mono-black     -> black-only print
  PNG sizes in the file name (e.g. -1600w = 1600 px wide). Use SVG for web and print.

02-App-Icon-Favicon
  App icons (blue, midnight, white), square avatars, and a full favicon set
  (favicon.ico, favicon.svg, apple-touch-icon, android icons, site.webmanifest, html snippet).

03-LinkedIn
  Banners: personal profile banner 1584x396 and company page cover 1128x191, 3 designs each
           (A midnight, B blue, C light), with @2x versions for sharp screens.
  Posts:   4 square post templates 1200x1200 + link share image 1200x627.
  Profile: company logo 400x400.
  Safe zone: your profile photo covers the bottom-left, so all text starts right of it.

04-Colors
  Palette image, CSS variables, JSON, Tailwind colors, and .ase swatches (Adobe / Figma plugins).

05-Typography
  Poppins Regular, Medium, SemiBold, Bold (.ttf, free OFL license) + type scale.

06-Print
  Business card PDF, 3.5 x 2 in with 0.125 in bleed on every side. Replace [YOUR NAME],
  [YOUR EMAIL], [YOUR PHONE] before printing (edit the SVG or ask Claude).

07-Email-Signature
  HTML signature + icon image.

RULES IN ONE MINUTE
  - Clear space around the logo = 2x the width of the orange dot.
  - Minimum size: mark 24 px, horizontal logo 120 px wide.
  - Never recolor the dot, stretch, rotate, add shadows, or put the color logo on busy photos.
  - Orange is a signal (about 3% of a page). Never white text on orange.
  - Emerald = verified / done. Red = missing / risk. Never use them as decoration.
  - Full guidelines: the Secuabase design system on Claude.
